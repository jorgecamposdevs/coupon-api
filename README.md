# 🏷️ Coupon API

API responsável pelo gerenciamento de cupons, permitindo **criação**, **remoção lógica (soft delete)** e controle de regras de negócio, desenvolvida com **Spring Boot 3** e **Java 21**.

---

## 🚀 Tecnologias Utilizadas

- Java 21
- Spring Boot 3.4.2
- Spring Web
- Spring Data JPA
- Bean Validation
- H2 Database (em memória)
- Lombok
- Swagger / OpenAPI (springdoc)
- JUnit 5 + Mockito

---

## 📌 Funcionalidades

- ✅ Criar cupom
- ✅ Validações de regras de negócio
- ✅ Soft delete (remoção lógica)
- ✅ Documentação automática via Swagger
- ✅ Banco de dados em memória (H2)
- ✅ Testes unitários
